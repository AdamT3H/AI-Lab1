Висновок: лишаю сервер. Він коштує ≈1,0k токенів на старті сесії з моделлю Auto за замовчуванням (близько 0,8% вікна в 128k) навіть без жодного виклику, а дає актуальні API Next.js 16 і zod 4. Найбільший споживач у моїй сесії Copilot не Context7, а вбудований github-mcp-server (6,1k), який я сам не підключав; у Codex є схожий вбудований `codex_apps` (14 інструментів), його ціну я не виміряв. Якщо контекст стане тісним, першим вимикатиму саме вбудовані сервери, а не Context7.
